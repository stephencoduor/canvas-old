# Changelog

## 0.1.0 (2026-10-17)

First build, covering the plan's modules A, B and C.

- Dates and Modules editor: unified date table in module order; shift forward or backward, weekend policy, set time, weekly pattern remap, set or clear; overrides; preview with validation; undo journal (last 10 per course); module unlock dates; bulk Sync to SIS with rule checks.
- Course Copy Auditor: content scan across pages, assignments, discussions, announcements, syllabus, classic quiz questions, New Quizzes items and modules; Canvas link validator merge; old-course link fixes by name match; CSV export.
- SpeedGrader Pro: snippets with variables, search, folders, tags, import and export; institution library from managed policy; rubric hotkeys; private notes; optional keyboard flow.
- Feature switches with institution policy override (`chrome.storage.managed`).
- Optional host permissions for school-owned Canvas addresses.

Not yet included: licensing and Pro gating (phase 2), the shared-library backend (phase 4), the LTI edition (phase 5).
